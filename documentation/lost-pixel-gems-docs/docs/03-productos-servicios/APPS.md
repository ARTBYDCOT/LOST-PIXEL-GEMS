# Apps & Pages (the multi-experience)

| Page | Experience |
|---|---|
| `index.html` | Home / metaverse entry |
| `lost-pixel-city.html` | The 3D city of gem-portals (first/third person) |
| `room.html` → `voxel-studio.html?play=1` | First-person spectator room (mirrors editor edits) |
| `voxel-studio.html` | Full MagicaVoxel-style voxel editor (`?gem=N` gem-room) |
| `lpg-map` (`/map/`) | Public voxel map — walk it **as a pixel** |
| `explorer.html` | On-chain explorer: gems, owners, transactions |
| `owners.html` | Collector ranking & ownership across 6 collections |
| `digital-life.html` | Gems evolve with real-world data |
| `game.html` | Interactive pixel-art game |
| `chat.html` | Community chat (server-backed) |

All experiences are connected: own a gem → edit its room → burn PIXELS to make it
permanent → it joins the shared 8M-voxel world everyone can walk.
