# LPG V1 Contract

## Overview
The Lost Pixel Gems V1 collection represents the first generation of 111 unique gems on the Ethereum mainnet.

## Contract Details
- **Contract Address:** `0xb52cD7A93878D823dF0fBc4F2E5a42f7b5B53A44`
- **Network:** Ethereum Mainnet
- **Type:** ERC-721 NFT Collection
- **Total Supply:** 111 gems
- **Status:** Live & Active

## Purpose
- Owner-gate for the Lost Pixel Gems map
- Genesis collection establishing the project's foundation
- Grants special access and privileges to holders

## Features
- Standard ERC-721 functionality
- Read-only calls: `balanceOf`, `ownerOf`, `totalSupply`
- ABI available in `contracts/abi/`

## Holder Benefits
- Map access and governance rights
- Foundation holder status
- Priority in future protocol developments
